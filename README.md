# Cyberpunk-Themed Portfolio

### A Futuristic Developer Portfolio Inspired by Cyberpunk 2077

A visually immersive, single-page developer portfolio built with **HTML, CSS, and Vanilla JavaScript**. Featuring a cinematic boot sequence, futuristic HUD interface, animated cyberpunk effects, interactive project cards, and multilingual support, this portfolio blends modern web development with sci-fi aesthetics.

---

## 📖 Overview

This project is a modern personal portfolio designed to showcase projects, skills, and experience through a unique cyberpunk-inspired interface.

Instead of a traditional portfolio, the site presents information as a futuristic operating system complete with animated HUD panels, glitch effects, scanlines, neon lighting, terminal-inspired components, and interactive "data shards."

Built entirely with **HTML**, **CSS**, and **Vanilla JavaScript**, the project requires no frameworks or build tools, making it lightweight, fast, and easy to deploy.
